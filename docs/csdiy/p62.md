# CMU 15-445 Lecture 02：Modern SQL 复习笔记

## 1. SELECT-FROM-WHERE：最基本查询

### 作用

从表里取出想要的列，并按条件过滤。

### 模板

```sql
SELECT 列1, 列2, ...
FROM 表名
WHERE 条件;
```

### 例子

```sql
SELECT sid, name
FROM student
WHERE gpa > 3.5;
```

### 语义

- `FROM`：先决定从哪张表取数据
- `WHERE`：对原始行做过滤
- `SELECT`：决定最后输出哪些列

### 易错点

- `WHERE` 过滤的是 **行**，不是分组结果
- `SELECT *` 虽然方便，但写题和调试时最好明确列名

------

## 2. 聚合函数：把多行压成统计值

### 常见聚合函数

```sql
COUNT(*)
SUM(x)
AVG(x)
MIN(x)
MAX(x)
```

### 模板

```sql
SELECT 聚合函数(列)
FROM 表名;
```

### 例子

```sql
SELECT AVG(gpa)
FROM student;
```

### 语义

把多行数据压成一个统计结果。

### 易错点

下面这种通常是错的：

```sql
SELECT AVG(gpa), name
FROM student;
```

因为 `AVG(gpa)` 想输出一行，`name` 却对应很多行，不知道该填谁。

------

## 3. GROUP BY：按组统计

### 作用

先按某个键分组，再对每组做聚合。

### 模板

```sql
SELECT 分组列, 聚合函数(列)
FROM 表名
GROUP BY 分组列;
```

### 例子

```sql
SELECT cid, AVG(grade)
FROM enrolled
GROUP BY cid;
```

### 语义

- 先按 `cid` 把行分桶
- 每个桶单独计算 `AVG(grade)`
- 每组输出一行

### 核心规则

`SELECT` 里出现的列：

- 要么是聚合结果
- 要么必须出现在 `GROUP BY` 里

### 易错点

```sql
SELECT sid, cid, AVG(grade)
FROM enrolled
GROUP BY cid;
```

这是错的。因为同一个 `cid` 组里可能有多个不同的 `sid`，无法确定输出哪个。

------

## 4. HAVING：对分组结果再过滤

### 作用

`WHERE` 过滤行，`HAVING` 过滤组。

### 模板

```sql
SELECT 分组列, 聚合函数(列)
FROM 表名
GROUP BY 分组列
HAVING 聚合条件;
```

### 例子

```sql
SELECT cid, AVG(grade)
FROM enrolled
GROUP BY cid
HAVING AVG(grade) > 90;
```

### 语义

- 先分组
- 再计算聚合
- 最后根据聚合结果过滤组

### 和 WHERE 的区别

```sql
-- 先删行，再分组
SELECT cid, AVG(grade)
FROM enrolled
WHERE grade >= 90
GROUP BY cid;
-- 先分组，再看整组平均值
SELECT cid, AVG(grade)
FROM enrolled
GROUP BY cid
HAVING AVG(grade) >= 90;
```

这两条 SQL 一般结果不同。

------

## 5. ORDER BY：排序

### 作用

明确规定输出顺序。

### 模板

```sql
SELECT 列
FROM 表名
ORDER BY 列 [ASC|DESC];
```

### 例子

```sql
SELECT sid, name, gpa
FROM student
ORDER BY gpa DESC;
```

### 说明

- `ASC`：升序，默认
- `DESC`：降序

### 易错点

表本身一般 **没有稳定顺序保证**。
不写 `ORDER BY`，就不要默认结果天然有序。

------

## 6. LIMIT：只取前几条

### 作用

限制输出行数。

### 模板

```sql
SELECT 列
FROM 表名
LIMIT k;
```

### 例子

```sql
SELECT *
FROM student
LIMIT 2;
```

### 关键理解

`LIMIT` 只负责截断，不负责定义顺序。

### 正确搭配

如果你想取“前 k 名”，必须配合 `ORDER BY`：

```sql
SELECT *
FROM student
ORDER BY gpa DESC
LIMIT 2;
```

## 7. JOIN：把两张表按条件拼起来

### 作用

从多张表中组合信息。

------

### 7.1 INNER JOIN

#### 模板

```sql
SELECT 列
FROM A
JOIN B ON A.x = B.x;
```

#### 例子

```sql
SELECT s.name, e.cid, e.grade
FROM student s
JOIN enrolled e
ON s.sid = e.sid;
```

#### 语义

只保留左右两边 **都能匹配上** 的行。

#### 关键理解

一条左表记录如果能匹配右表多条记录，结果会扩成多行。

------

### 7.2 LEFT JOIN

#### 模板

```sql
SELECT 列
FROM A
LEFT JOIN B ON A.x = B.x;
```

#### 例子

```sql
SELECT s.sid, s.name, e.cid
FROM student s
LEFT JOIN enrolled e
ON s.sid = e.sid;
```

#### 语义

- 左表所有行都保留
- 右表找不到匹配时补 `NULL`

#### 高频用途：找“左边没有匹配”的行

```sql
SELECT s.sid, s.name
FROM student s
LEFT JOIN enrolled e
ON s.sid = e.sid
WHERE e.sid IS NULL;
```

表示：找没有选课的学生。

------

## 8. 子查询（Subquery）

### 作用

把一个查询结果拿给另一个查询使用。

### 模板

```sql
SELECT 列
FROM 表名
WHERE 某列 IN (
    SELECT 列
    FROM 另一张表
    WHERE 条件
);
```

### 例子

```sql
SELECT name
FROM student
WHERE sid IN (
    SELECT sid
    FROM enrolled
    WHERE cid = 15445
);
```

### 语义

- 内层先查出一批 `sid`
- 外层再去 `student` 里找这些人的名字

### 常见形式

- `IN (subquery)`
- `EXISTS (subquery)`
- `FROM (subquery) AS t`

------

## 9. CTE：给中间结果起名字

### 作用

把复杂 SQL 拆成更清楚的几步。

### 模板

```sql
WITH 临时表名 AS (
    子查询
)
SELECT ...
FROM 临时表名;
```

### 例子

```sql
WITH selected_sid AS (
    SELECT sid
    FROM enrolled
    WHERE cid = 15445
)
SELECT name
FROM student
WHERE sid IN (SELECT sid FROM selected_sid);
```

### 语义

`selected_sid` 只是当前 SQL 内部的临时名字，不是永久表。

## 10. Window Function：按组算，但不压缩行数

### 作用

既想保留原始每一行，又想得到“组内统计值 / 排名”。

------

### 10.1 组内最大值

#### 模板

```sql
SELECT 列,
       聚合函数(列) OVER (PARTITION BY 分组列) AS 新列
FROM 表名;
```

#### 例子

```sql
SELECT sid, cid, grade,
       MAX(grade) OVER (PARTITION BY cid) AS max_in_cid
FROM enrolled;
```

#### 语义

- 按 `cid` 分组
- 计算每组最大值
- 但不把组压成一行
- 而是把结果贴到组内每一行上

------

### 10.2 组内排名

#### 模板

```sql
SELECT 列,
       RANK() OVER (
           PARTITION BY 分组列
           ORDER BY 排序列 DESC
       ) AS rk
FROM 表名;
```

#### 例子

```sql
SELECT sid, cid, grade,
       RANK() OVER (
           PARTITION BY cid
           ORDER BY grade DESC
       ) AS rk
FROM enrolled;
```

#### 高频用途

找每组前 k 名：

```sql
SELECT *
FROM (
    SELECT sid, cid, grade,
           RANK() OVER (
               PARTITION BY cid
               ORDER BY grade DESC
           ) AS rk
    FROM enrolled
) t
WHERE rk <= 2;
```

------

## 11. 这一课最重要的区分

### 11.1 WHERE vs HAVING

- `WHERE`：过滤原始行
- `HAVING`：过滤分组结果

### 11.2 GROUP BY vs Window Function

- `GROUP BY`：一组通常输出一行
- `WINDOW`：保留原始行数，只是多出统计列

### 11.3 ORDER BY vs LIMIT

- `ORDER BY`：定义顺序
- `LIMIT`：截断结果

### 11.4 INNER JOIN vs LEFT JOIN

- `INNER JOIN`：只保留匹配上的
- `LEFT JOIN`：左边全保留，右边匹配不到补 `NULL`

------

## 12. 推荐的 SQL 阅读顺序

看到一条 SQL，建议你按下面顺序理解：

```text
FROM / JOIN
-> WHERE
-> GROUP BY
-> HAVING
-> SELECT
-> ORDER BY
-> LIMIT
```

这是很好的学习模型。

## 13. 高频模板速查

### 13.1 查符合条件的行

```sql
SELECT *
FROM student
WHERE gpa > 3.5;
```

### 13.2 求整张表统计值

```sql
SELECT AVG(gpa)
FROM student;
```

### 13.3 每组统计

```sql
SELECT cid, AVG(grade)
FROM enrolled
GROUP BY cid;
```

### 13.4 过滤平均值大的组

```sql
SELECT cid, AVG(grade)
FROM enrolled
GROUP BY cid
HAVING AVG(grade) > 90;
```

### 13.5 排序后取前 k 名

```sql
SELECT *
FROM student
ORDER BY gpa DESC
LIMIT 3;
```

```sql
SELECT s.name, e.cid
FROM student s
JOIN enrolled e
ON s.sid = e.sid;
```

### 13.7 找左边没有匹配的行

```sql
SELECT s.sid, s.name
FROM student s
LEFT JOIN enrolled e
ON s.sid = e.sid
WHERE e.sid IS NULL;
```

### 13.8 子查询

```sql
SELECT name
FROM student
WHERE sid IN (
    SELECT sid
    FROM enrolled
    WHERE cid = 15445
);
```

### 13.9 CTE

```sql
WITH t AS (
    SELECT sid
    FROM enrolled
```
